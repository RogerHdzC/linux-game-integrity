# Security

This is experimental inventory software. Do not use it to admit players to
competitive games. There is no production release or machine-integrity guarantee.

For a problem without sensitive details, open an issue with a synthetic example.
For a vulnerability needing private disclosure, use GitHub's private reporting
option if the repository offers it. Otherwise open an issue requesting a private
channel without including exploit details or secrets. No response-time guarantee
or bug bounty is offered.

Never attach private EK/AK material, tokens, unreviewed inventories, memory dumps
or IMA logs containing personal paths. Do not test hypotheses against Riot,
players or third-party services. Use only your authorized lab.
