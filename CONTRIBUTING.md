# Contributing

Open an issue describing the problem, distribution/kernel and minimal steps to
reproduce it. Discuss substantial design changes first. Submit small PRs with
tests, contract updates when needed, and documentation in English.

Run the quality commands in README. Clearly label every synthetic fixture. VM
results never substitute for validation on a physical TPM. Share only reviewed
summaries of real experiments: environment, interfaces, errors and commands.
Remove identifiers and private paths before posting.

Anti-cheat evasion, game injection, process hiding, forged evidence and
unauthorized Vanguard modifications are outside this project's scope.
Contributions must be reviewable in an independent lab.

By contributing, confirm that you have the right to submit the work under
Apache-2.0. Preserve third-party attribution and licenses. Do not copy code with
unknown provenance or licensing. No additional CLA is required at this stage.

Treat participants respectfully, make technical criticism specific, and never
publish another person's private information. Independent security review is
particularly welcome for trust assumptions and the limits of experimental results.
